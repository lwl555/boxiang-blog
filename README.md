# 薄想接单博客 · 项目说明

一个以接单为主的个人博客网站：3D 动画风格（深色 + 琥珀金暖色系，避开 AI 常用蓝色），带接单表单、作品展示、博客和后台管理。

## 技术栈
- 前端：原生 HTML/CSS/JS + Three.js（3D 动画）+ Supabase JS SDK
- 后端：Supabase（免费档，现有项目 wcnssyiqitugqfmcbdhe）
- 部署：GitHub Pages

## 目录结构
- `index.html` —— 前台主页（首页/关于/服务/作品/博客/接单表单）
- `admin.html` —— 后台管理（登录后管理订单、内容、站点设置）
- `css/` —— 样式（前台 + 后台）
- `js/` —— 逻辑（3D 场景、前台、后台、Supabase 配置）
- `sql/init.sql` —— 数据库初始化脚本（建表 + 权限 + 默认数据）
- `assets/` —— 静态资源与截图

## 上线前需要你做 2 步（约 3 分钟）

### 第 1 步：执行建表 SQL
1. 打开 https://supabase.com/dashboard → 登录 → 进入现有项目（wcnssyiqitugqfmcbdhe）
2. 左侧菜单选 **SQL Editor**（SQL 编辑器）→ 点 **New query**（新建查询）
3. 把本目录下 `sql/init.sql` 的全部内容粘贴进去
4. 点 **Run**（运行），看到绿色成功提示即可

### 第 2 步：创建管理员账号
1. 左侧菜单选 **Authentication**（身份验证）→ **Users**（用户）
2. 点 **Add user**（添加用户）→ 填你的邮箱和密码（这就是后台登录账号）
3. 保存即可

完成后访问 `admin.html`，用刚创建的邮箱密码登录，即可：
- 📋 查看/处理接单需求（改状态、复制联系方式、删除）
- 📝 管理作品和博客（增删改、发布/隐藏）
- ⚙️ 修改站点内容（昵称、简介、抖音号、公众号、服务列表等）
